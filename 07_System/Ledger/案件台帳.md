## 書き方のルール

- **案件ID**: `05_Output/Projects/@Active/` のフォルダ名と揃える
  → これで `h3log.py report --project (案件ID)` が使えるようになります
- **状態**: 企画中 / 制作中 / 確認待ち / 修正中 / 納品済
- **請求**: 未 / 済(日付)
- **入金**: 未 / 済(日付)
- 完了したら「完了」の表に移し、**原価と粗利を必ず記入する**
  → 次の案件の見積もり精度が上がります

## 原価の出し方

```bash
python3 scripts/h3log.py report --project (案件ID) \
  --jpy 155 --labor-hours (制作時間) --labor-rate (時間単価) \
  --out "05_Output/Projects/@Active/(案件ID)/原価レポート.md"
```

または、経理チームに頼んでください。
