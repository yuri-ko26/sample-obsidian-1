# 👥 チーム

> 百合子さんを社長として、4つのチームが動きます。
> **いまはAIチームです。案件と売上が増えたら、順番に人に置き換えていきます。**

---

## メンバー

| チーム | 呼び方 | 担当 |
|---|---|---|
| 🎬 **制作チーム** | `/seisaku` | H3プロンプトの起草・改稿、キャラ一貫性、次版の設計、生成ログ |
| 💰 **経理チーム** | `/keiri` | 案件別の原価、経費、請求書の下書き、月次サマリー |
| 📋 **秘書チーム** | `/hisho` | 納期管理、スケジュール、案件ステータス、今日やること |
| 🌱 **コーチングチーム** | `/coach` | 週次振り返り、目標の進捗、軸の確認、壁打ち |

**Claude Code**: 「制作チームに聞いて」「経理チーム、今月の数字出して」のように頼めば、
該当のチームが立ち上がります。
**Cursor**: チャットで `/seisaku` `/keiri` `/hisho` `/coach` と打ってください。

## 使い分けの目安

| こんなとき | 呼ぶチーム |
|---|---|
| プロンプトを直したい / 生成結果が思い通りにならない | 🎬 制作 |
| この案件、いくら儲かったんだろう | 💰 経理 |
| 請求書を出さないと / 入金まだかな | 💰 経理 |
| 今日何からやればいい? | 📋 秘書 |
| 納期、間に合う? | 📋 秘書 |
| 打ち合わせのメモを整えたい | 📋 秘書 |
| 今週を振り返りたい | 🌱 コーチング |
| この案件、受けるべきか迷う | 🌱 コーチング |
| 何か行き詰まっている | 🌱 コーチング |

## チームが動くために必要なもの

チームは**台帳を見て判断します。** ここが空だと何もできません。

| 台帳 | 使うチーム | 状態 |
|---|---|---|
| `07_System/Ledger/案件台帳.md` | 💰 経理 / 📋 秘書 | ⚠️ **金額・納期の記入が必要** |
| `07_System/Ledger/生成ログ.csv` | 🎬 制作 / 💰 経理 | ✅ 記録開始待ち |
| `07_System/Ledger/Pod稼働ログ.csv` | 💰 経理 | ✅ 記録開始待ち |
| `03_Input/this-month-goals.md` | 🌱 コーチング | 既存 |

> 💡 **まず `案件台帳.md` を埋めてください。** ここが埋まった瞬間に、
> 経理チームと秘書チームが本当に使えるようになります。

## チームの育て方

各チームの中身は `.claude/agents/*.md` に書いてあります。
**普通の日本語のファイルなので、いつでも編集できます。**

- 「秘書チームがもっと厳しく締切を言ってほしい」→ `hisho.md` に書き足す
- 「経理チームに、こういう形式で出してほしい」→ `keiri.md` に書き足す
- 「制作チームは、この演出のクセを覚えておいて」→ `seisaku.md` に書き足す

**使いながら育ててください。** 最初から完璧である必要はありません。
うまくいったやり取りがあったら、その要点をファイルに書き足しておくと、
次から同じ質でやってくれます。

## いつ、人に置き換えるか

| チーム | 人に渡すタイミングの目安 |
|---|---|
| 💰 経理 | 年商1,000万円前後(消費税の課税事業者になる頃)→ **税理士さんが最初** |
| 📋 秘書 | 同時進行の案件が**常時4件**を超えたら |
| 🎬 制作 | 自分一人では納期に間に合わない案件が続いたら → **まず外注から** |
| 🌱 コーチング | 事業の相談相手が必要になったら(メンター/経営者仲間) |

> 💡 **順番はたいてい「税理士 → 制作の外注 → 事務」です。**
> いきなり正社員を雇わないこと。固定費は、売上が安定してから。
> 具体的な計画が必要になったら、🌱 コーチングチームに相談してください。
