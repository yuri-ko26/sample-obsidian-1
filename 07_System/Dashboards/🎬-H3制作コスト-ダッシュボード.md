# 🎬 H3制作コスト・ダッシュボード

> 「どの動画を、どのプロンプトで、どのモデルで作ったか」と
> 「その案件にいくらかかったか」を記録・集計する場所です。
> 環境そのものの方針は [[00-結論とロードマップ]] に。

---

## 仕組み(3層になっています)

```
① プロンプト本文        02-scenes-v2/(カット名).md
   ├ v1 / v2 と版で追記      ← いままで通り。ここは変えません
   └ 判定・メモ

② 数字の台帳            07_System/Ledger/
   ├ 生成ログ.csv            ← 1生成 = 1行(モデル・GPU・seed・金額)
   └ Pod稼働ログ.csv         ← 1セッション = 1行(実際に課金された時間)

③ 出力                  h3log.py report / decide
   ├ クライアント提示用の原価レポート
   └ 借りる/買う の判定
```

**①は人が読むもの、②は集計するもの。** `prompt_ref` 列で①と②が繋がるので、
CSVの1行から必ずプロンプト全文にたどり着けます。

---

## 毎日の3コマンド

vaultのフォルダで実行してください。

### 1. Podを立てたら、すぐ

```bash
python3 scripts/h3log.py pod start \
  --project H3-Video-Series --gpu "L40S" --rate 0.86
```

### 2. 1本生成するたびに

```bash
python3 scripts/h3log.py gen add \
  --project H3-Video-Series --cut C-2d --version v2 \
  --mode I2VA --quant int8 --compute-s 200 \
  --duration 7 --resolution 864x480 --seed 12345 \
  --video C2d_v2.mp4 --verdict OK \
  --prompt-ref "05_Output/Projects/@Active/H3-Video-Series/02-scenes-v2/C2d-tamachan-running-start-bump.md" \
  --note "ぽよんも転がるオチに変更。採用"
```

> 💡 `--gpu` と `--rate` は `pod start` の値が自動で入るので省略できます。
> 💡 長いので、**Cursorに `/h3-log` と打つ**のがおすすめです
>    (`.cursor/commands/h3-log.md` に登録済み)。

### 3. Podを停めたら、すぐ

```bash
python3 scripts/h3log.py pod end
```

> ⚠️ **`pod end` を忘れると、次に `pod start` できません。**
> これは仕様です。停め忘れを防ぐための安全装置になっています。

## クライアントに原価を提示する

```bash
python3 scripts/h3log.py report \
  --project H3-Video-Series \
  --since 2026-09-01 --until 2026-09-30 \
  --jpy 155 --labor-hours 26 --labor-rate 8000 \
  --out "05_Output/Projects/@Active/H3-Video-Series/原価レポート-2026-09.md"
```

出てくるもの:

- 生成回数・採用カット数・**作り直し率**
- GPU実生成時間 / 課金時間 / **稼働効率**
- 費用内訳(**GPU実費 + 制作作業費 + その他 = 合計**)
- カット別の一覧(版・モード・モデル・判定・ファイル名)

> 💡 `--labor-rate` は自分の時間単価です。年商700万円・稼働を考えると
> **¥8,000〜12,000/時**あたりが一つの目安になります。案件により調整してください。

> 💡 **「作り直し率」は見積もりの精度を上げる武器です。**
> 「このタッチのキャラは平均2.4回で決まる」と分かれば、
> 次の案件の工数を勘ではなく数字で見積もれます。

## 借りる/買う を判定する

2〜4週間ぶんの記録が貯まったら:

```bash
python3 scripts/h3log.py decide \
  --jpy 155 --machine-cost 1060000 --years 4
```

実測の課金時間から損益分岐点を計算して、判断材料を出します。
背景と結論は [[02-GPU比較とローカルPC構成案]] に。

## 記録が途切れたときの直し方

**後からまとめて入れられます。** 完璧でなくて大丈夫です。

```bash
# 昨日8時間動かしたのを入れ忘れた
python3 scripts/h3log.py pod add --project H3-Video-Series \
  --gpu "L40S" --rate 0.86 --start "2026-09-09T10:00" --minutes 480
```

CSVを直接Obsidianやテキストエディタで開いて手で直しても構いません。
**続けられることの方が、正確さより大事です。**

## 台帳の列の意味

### 生成ログ.csv

| 列 | 意味 |
|---|---|
| `timestamp` | 記録した日時 |
| `project` / `cut` / `version` | どの案件の、どのカットの、第何版か |
| `mode` | I2VA / FL2VA など |
| `model` / `quant` | モデル名と量子化(bf16 / int8 / nvfp4) |
| `gpu` / `rate_usd_hr` | 使ったGPUと時間単価 |
| `compute_s` / `cost_usd` | 生成にかかった秒数と金額 |
| `resolution` / `duration_s` / `steps` / `seed` | 再現に必要な設定 |
| `video` | 保存した動画ファイル名 |
| `verdict` | OK / NG / 未検証 |
| **`prompt_ref`** | **プロンプト全文があるノートのパス** |
| `note` | 気づいたこと(**ここがいちばん資産になります**) |

### Pod稼働ログ.csv

| 列 | 意味 |
|---|---|
| `start` / `end` / `billed_s` | 課金された時間 |
| `cost_usd` | その回の金額 |
