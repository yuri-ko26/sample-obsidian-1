# 音楽MV｜コマ撮り「愛の装置」全5カット

## 構成とカット割り

| Cut | 内容 | 尺 |
|-|-|-|
| 1 | キャラクターが演奏、楽器から手描きの音符が放たれる | 6.00s |
| 2 | 音符が漂いながら少しずつハートの形に変わる | 6.00s |
| 3 | ハートが愛の装置に吸い込まれ、装置が回り出す | 6.00s |
| 4 | ゾートロープの回転が加速し、花火が打ち上がる | 6.00s |
| 5 | 花火を背景にキャラクターたちが演奏する | 6.00s |
| | **合計** | **30.00s** |

### 設計メモ

- **6秒には全構成が入らないため5分割しました。** 7ビートを6秒に詰めると各要素が1秒未満になり、コマ撮りの「間」が潰れます。
- **全カット単一ショット。** 6秒でカットを割ると1カット3秒弱になり、コマ送りの動きが途中で切れます。変化はカメラワークとワンアクションに集約しています。
- **`non_diegetic_music` は全カット `N/A`。** キャラクターが実際に楽器を鳴らしているため、その音は劇中音として `integrated_multimodal_description` 側に記述する必要があります。MV楽曲は後乗せなので劇伴欄は空けます。
- **セリフ・オンスクリーン文字なし。** 話者ID `(S1)` と `<d>` ブロックは全カットで未使用です。

### 第1フレーム画像の準備

I2VA なので各カットに1枚ずつ、計5枚のキーフレーム画像が必要です。
**繋ぎを合わせるコツ：前カットの最終フレームを書き出して、次カットの `<Picture 1>` に使う**と、パペットの位置・光・セットの連続性が保てます。

Cut 2（音符 → ハートの変形）だけは開始形と終了形が明確なので、**FL2VA に切り替えると変形の経路をより正確に制御できます。** その場合は1行目を以下に差し替えてください。

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot 1) aligns with the 6.00-second mark of the target video.
```
