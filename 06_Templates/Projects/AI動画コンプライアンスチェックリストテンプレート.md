# {{project}} — AI動画制作コンプライアンスチェックリスト

企業クライアント向けにAI動画を制作する際、契約前に確認する項目のテンプレート。詳細な考え方は `05_Output/Projects/@Active/AI-Video-Enterprise-Client/01-コンプライアンス環境構築ガイド.md` を参照。

## ツール選定
- [ ] 使用予定ツールをすべてBusiness/Team/Enterprise/API契約に統一した
- [ ] 各ツールの「モデル改善への利用」トグルをOFFにした（スクリーンショット保存済み）
- [ ] コミュニティ投稿・公開ギャラリー機能をOFFにした
- [ ] 生成物の権利帰属・商用利用可否を規約で確認した
- [ ] IP侵害補償の有無を確認した

## ログ・記録
- [ ] プロンプトログの記録フォーマットを用意した
- [ ] 出力ファイルのハッシュ取得を運用に組み込んだ
- [ ] ログ保存先をGit等で版管理している
- [ ] 保存期間・削除ポリシーをクライアントと合意した

## 監査・第三者保証
- [ ] 使用ツールのSOC2/ISO27001/Trust Center資料を収集した
- [ ] 「個人契約では監査を担保できない」旨をクライアントに開示し合意を得た

## クライアント合意
- [ ] 説明資料を送付した
- [ ] 使用ツール一覧について承認を得た
- [ ] 契約書に責任範囲（自己記録 vs ベンダー依存部分）を明記した

## 運用開始後
- [ ] 生成のたびにプロンプトログを記録している
- [ ] 月次で規約変更の有無を確認している
- [ ] 案件終了時にログ・素材をアーカイブし、削除ポリシーに従って処理した
