# 生成動画の保存ルール

Runpod上のComfyUIは生成後にファイルが消えてしまうため、生成した動画は
**必ずここにダウンロードして保存**し、対応する `02-scenes-v2/` のシーンファイルの
「プロンプト履歴」に記録する。これにより、どのバージョンのプロンプトでどの動画が
生成されたかが後から必ず追跡できる。

## ファイル名のルール
```
sceneNN_vX.mp4
```
- `NN` = シーン番号(例: 01, 02...)
- `vX` = そのシーンのプロンプトのバージョン番号(例: v1, v2...)
- 例: `scene01_v1.mp4`、`scene01_v2.mp4`(v1を直した2回目の生成)

## 保存の手順
1. Runpod/ComfyUIで動画を生成したら、Podを閉じる前に必ず動画をローカルにダウンロードする
2. このフォルダに `sceneNN_vX.mp4` の名前で保存する
3. 対応する `02-scenes-v2/sceneNN-*.md` の「プロンプト履歴」内、該当バージョンの
   「生成結果」欄にファイル名と判定(OK/NG)・メモを記入する

これで、どのプロンプト文でどの動画ができたかが常にペアで残り、
うまくいったプロンプトを後から見返して他のシーンに応用しやすくなる。
