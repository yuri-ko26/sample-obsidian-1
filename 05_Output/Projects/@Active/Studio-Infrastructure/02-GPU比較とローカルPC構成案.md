# GPU比較とローカルPC構成案

> ⚠️ 価格は2026年9月時点の調査値です。**特にRTX 5090は品薄で価格変動が激しい**ため、
> 発注前に必ず現在価格を確認してください。

---

## 結論を先に

**いま慌てて買わないでください。理由は2つあります。**

1. **[[01-いますぐやるRunPodコスト削減]] をやれば、恐怖は今週消えます。**
   月12.7万円 → 月1.4万円。買う判断を急ぐ理由がなくなります。

2. **RTX 5090はいま「品薄プレミアム」が乗っています。**
   定価 **¥393,800** に対し、実勢 **¥690,000〜790,000**。
   **約30万円が品薄による上乗せ分**です。急がないなら、これを払う必要はありません。

**推奨:** RunPodを整えて4週間データを取る → その数字で決める。
買うなら「安いから」ではなく「**機密保持と、使い放題の安心のため**」に買う。

---

## 1. H3にはどのGPUが必要か

H3のオープンウェイトの実態:

| | |
|---|---|
| モデル本体 | 42.5GB |
| 枝刈り+int8版 | **31.7GB** ← 32GBのGPUに収まる |
| 推奨VRAM | 24GB以上(32GBで余裕) |
| 実用下限 | 12GB(品質は落ちる) |
| システムRAM | **64GB以上、できれば128GB** |
| 出力解像度 | 768pベース(2KはAPI版のみ) |

**実測されている生成速度**

| GPU | 内容 | 時間 |
|---|---|---|
| RTX 5090 (32GB) | 10秒 / 864×480 | **175秒** |
| RTX 5090 (32GB) | 15秒 / 1080p(VSR併用・ステップ削減) | 314秒 |
| RTX 3060 (12GB) | 5秒 / 768p級 | 6〜25分 |

→ **80GBのH100 SXMは、この用途には明確に過剰です。**

## 2. 借りる場合の比較(RunPod)

| GPU | VRAM | 単価/時 | H100 SXM比 | 評価 |
|---|---|---|---|---|
| H100 SXM(現在) | 80GB | $3.29 | — | 過剰 |
| H100 PCIe | 80GB | $2.89 | 1/1.1 | 量子化を一切避けたい場合の保険 |
| **L40S** | **48GB** | **$0.86** | **1/3.8** | ⭐ **まずここ。余裕があり最安級** |
| RTX 5090 | 32GB | $0.99 | 1/3.3 | 速度重視。実測データが豊富 |
| RTX 4090 | 24GB | $0.69 | 1/4.8 | 最安。量子化が強く必要 |

> ⭐ **L40S(48GB)を推します。** 48GBあれば量子化を弱められるので画質の変化が
> いちばん小さく、しかもRTX 5090より安い。乗り換えテストは
> [[01-いますぐやるRunPodコスト削減]] のSTEP 3に手順があります。

## 3. 買う場合の構成案

### 案A ─ RTX 5090構成(推奨)

H3の枝刈りint8版(31.7GB)が**VRAMに完全に収まる**構成です。

| パーツ | 目安 | 金額目安 |
|---|---|---|
| **GPU: RTX 5090 32GB** | 定価¥393,800 / **実勢¥690,000〜790,000** | **¥700,000** |
| CPU | Ryzen 9 / Core Ultra 9 クラス | ¥80,000 |
| マザーボード | PCIe 5.0対応・メモリ4スロット | ¥50,000 |
| **メモリ 128GB** | DDR5(H3のオフロードに効く。**削らないで**) | ¥80,000 |
| SSD | NVMe 2TB(システム+モデル)+ 4TB(素材) | ¥60,000 |
| 電源 | **1200W以上**(5090は瞬間的に大きく振れます) | ¥40,000 |
| ケース・冷却 | エアフロー重視 | ¥40,000 |
| OS | Windows 11 Pro | ¥20,000 |
| **合計** | | **約¥1,060,000** |

> 💡 **メモリ128GBは削らないでください。** H3はVRAMに乗り切らない部分を
> システムRAMに逃がします。ここが64GBだと、せっかくのGPUが待たされます。

> 💡 **価格が落ち着けば¥750,000前後**まで下がる可能性があります(GPU定価分)。
> 急ぎでなければ、価格推移を見る価値があります。

### 案B ─ RTX PRO 6000 Blackwell 96GB構成

| | |
|---|---|
| GPU単体 | 約$12,380(**約¥190万円**) |
| 構成合計 | **約¥230万円** |
| 速度 | RTX 5090の **+10〜15%程度** |
| 利点 | 量子化なしのbf16で動く。長尺・高解像度に強い |

> **現時点では推奨しません。** 3倍以上の価格差に対して速度は1.1倍。
> 「量子化なしで完全な品質」に価値が出るのは、もっと大きな案件を
> 継続的に受けるようになってからで十分間に合います。

### 案C ─ 中古RTX 4090(24GB)

VRAM 24GBだとint4/GGUFなど強めの量子化が必要になり、**キャラクターの
一貫性が崩れやすくなります**。百合子さんの作品は
「たまちゃんに眉毛が生えない」「ぽよんの口が開きすぎない」といった
**細部の一貫性が命**なので、ここを削るのは勧めません。

## 4. 借りる vs 買う ─ 3つのシナリオ

`scripts/h3log.py decide` で計算した実際の数字です。
(PC ¥1,060,000 / 4年償却 / 電気代 0.8kW・¥31/kWh)

| | 月額 |
|---|---|
| 借りる | **¥127,488** |
| 買う | ¥28,283 |

分岐点 月55時間(1日1.8時間)。現在は月250時間 = **分岐点の4.5倍**
→ **買う方が年間119万円安い**

### B) L40Sに替えるだけ(時間はそのまま)

| | 月額 |
|---|---|
| 借りる | **¥44,434** |
| 買う | ¥30,350 |

分岐点 月228時間(1日7.6時間)。現在は月333時間 = 分岐点の1.5倍
→ **買う方が年間17万円安い**(差は小さくなった)

### C) L40S + バッチ運用(1日2.5時間)★これが目標地点

| | 月額 |

## 5. だから、どう決めるか

シナリオCまで到達すると、**費用の差は月わずか¥11,233**になります。
この金額で何を買うのか、が本当の判断です。

### 月¥11,233で買えるもの

**① クライアント情報が一歩も外に出ない**
キャラクター設定も未公開の絵コンテも、事務所の外に出ません。
守秘義務の厳しい案件では、これが受注条件になることもあります。
→ [[03-クライアント情報とライセンス]]

**② メーターが止まる**
百合子さんが書かれた
「膨大なコストがかかってくる恐怖から、安心して思う存分生成したい」に
まっすぐ効くのはこれだけです。借りている限り、たとえ月1.3万円でも
「いま1本試すといくら」は頭から消えません。

買えば**限界費用がゼロ**になります。
「もう1回だけ試してみよう」が無料になる。
**作品の質は、たいていその『もう1回』から生まれます。**

**③ 起動の摩擦がゼロ**
思いついた瞬間に生成できる。Podを立てる15分がなくなります。

### 購入に踏み切る条件(どれか1つでも当てはまれば)

- [ ] 4週間の実測で、月の課金時間が **180時間**(1日6時間)を超えている
- [ ] 守秘義務の厳しい案件が入り、外部クラウドが使えない
- [ ] RTX 5090の実勢価格が **¥500,000を下回った**
- [ ] 「メーターを気にせず作りたい」気持ちが、月1.1万円より大きいと感じる

**4つ目は数字ではありませんが、いちばん正当な理由だと思います。**

## 6. 経費の扱い(要・税理士確認)

> ⚠️ 以下は一般的な扱いの説明です。**必ず顧問税理士に確認してください。**

- パソコンの法定耐用年数は通常 **4年**
- ¥1,060,000 は少額資産の特例(30万円未満)の範囲外なので、
  **4年かけて減価償却**するのが原則
- 定額法なら **年間約¥265,000** が経費になる計算
- 事業専用で使うなら、通常は全額を事業用資産として扱えます
- 青色申告をされている場合、適用できる特例が他にないかも確認する価値があります

**売上規模(年間約700万円)から見て、106万円の設備投資は
無理のある金額ではありません。**ただし、上で見た通り
**急いで買う必要はない**ので、キャッシュフローに余裕のあるタイミングで
判断すれば十分です。

## 7. 買った後もRunPodは解約しない

**ハイブリッドが正解です。**

| 状況 | 使うもの |
|---|---|
| 日常の制作・試行錯誤 | **ローカルPC**(無料・無制限) |
| 納期が重なって並列で回したい | RunPodを追加で立てる |
| 長尺・高解像度で一時的にVRAMが要る | RunPodのH100/L40S |
| PCが故障した | RunPod(業務が止まらない) |

ローカルを持っていても、RunPodは**月0円で置いておけます**(使った時だけ課金)。
Network Volumeだけ月1,600円残しておけば、いつでも数分で復帰できます。
**これが「安心して制作に打ち込める環境」の完成形**だと思います。
