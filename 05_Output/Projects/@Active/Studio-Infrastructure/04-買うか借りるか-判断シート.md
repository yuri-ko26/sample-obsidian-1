# 買うか借りるか ─ 判断シート

> 「決断できない」ときは、たいてい**答えが出ないのではなく、問いが混ざっています。**
> このシートは、混ざった問いをほどいて、順番に片付けるためのものです。

---

## 1. まず、問いを2つに分ける

いま百合子さんの中で1つになっているこの問いは、実は**別々の2つ**です。

### 問いA:「月12.7万円を払い続けるのをやめるべきか?」

**→ 答え: はい。今週。議論の余地はありません。**

これは決断ではなく**作業**です。Network Volumeを付けてGPUを替えるだけ。
45分で終わり、月12.7万円 → 月1.4万円になります。
**ここに悩む要素は1つもありません。** → [[01-いますぐやるRunPodコスト削減]]

### 問いB:「月1.3万円で借り続けるか、106万円で買うか?」

**→ これが本当の決断です。そして答えは『どちらでも間違いではない』。**

だから決められないんです。**間違いではないものの間で悩んでいるから。**

---

## 2. なぜ苦しいのかというと

いま百合子さんは、**月12.7万円の恐怖の中で、106万円の決断をしようとしています。**

これは判断としていちばん難しい状態です。追い詰められている時の大きな買い物は、
たいてい「逃げるための買い物」になります。そして後から見ると、
**焦っていなければ選ばなかった条件**で買っていることが多い。

しかも今は、RTX 5090に**約30万円の品薄プレミアム**が乗っています
(定価¥393,800 / 実勢¥690,000〜790,000)。

**順番を逆にしてください。**

```
✕  106万円を決断する → 恐怖が消える
◯  今週45分で恐怖を消す → 落ち着いて106万円を決断する
```

**恐怖を消すのに106万円は要りません。1,600円(Network Volume代)で消えます。**

---

## 3. ただし、1つだけ先に確かめることがある

**買う/借りる以前に、確かめないといけないことがあります。**

> **32GBのGPUで、百合子さんの品質基準を満たせるか?**

これが分からないと、どちらも決められません。理由:

| テスト結果 | 意味すること |
|---|---|
| **32GBで品質OK** | 買うなら **RTX 5090構成 ¥1,060,000** が選択肢になる |
| **48GB以上が必要** | 買うなら **RTX PRO 6000構成 ¥2,300,000**。年商の33%。**現実的でない**<br>→ **借りる一択**(L40S 48GBが月1.3万円で、しかも高品質) |

つまり **「48GB必要」なら、悩みは消えます。借りる、で確定です。**

そして幸運なことに、**このテストは1回¥300、半日で終わります。**

### 品質テストの手順(今週)

1. **L40S 48GB**($0.86/hr)でPodを立てる
2. `C-2d` v1 を、**まったく同じプロンプト・同じ参照画像・同じseed**で再生成
3. `03-generated-videos/C2d_v1.mp4`(H100版)と並べて見比べる
4. **RTX 5090相当(32GB)の条件**でも同じことをする
   (量子化を int8 / nvfp4 に上げて、VRAM 32GB以内に収める設定)

### 判定チェックリスト

百合子さんが `character-reference.md` で指定されている項目そのものです。

- [ ] たまちゃんに**眉毛が生えていない**
- [ ] たまちゃんの笑い顔で**目が三日月**になり、口にコーラルピンクが見える
- [ ] ぽよんの口が**顔の横幅の1/3を超えて開いていない**
- [ ] ぽよんの口が**輪郭線のみ・無着色**で、中のガムボールが透けている
- [ ] 接触時にぽよんが**丸みを保っている**(平らになっていない)
- [ ] ガムボール・紙吹雪が**こぼれていない**
- [ ] 全体の色味・質感がH100版と比べて劣化していない

**7項目中6つ以上OK → 32GBで通る**
**5つ以下、または「眉毛」「ぽよんの口」が崩れる → 48GB必要**

> ⚠️ 「眉毛」と「ぽよんの口」は百合子さんが何度もプロンプトで
> 念押ししている項目です。**ここが崩れたら即・不合格**と判断してください。

---

## 4. テスト結果 → 決断(自動的に決まります)

### ケース1: 48GB以上が必要だった

**→ 借りる。確定。悩まなくていい。**

- L40S 48GB を月1.3万円で使う
- **買うより安く、しかも品質が高い**という理想的な結論
- 年間15.6万円。106万円を使わずに済み、その資金は事業に回せる
- この場合、PCの話は**1年後に再検討**でOK(その頃には価格も性能も変わっています)

### ケース2: 32GBで品質が通った

**→ 「買う人」です。あとは時期だけの問題。**

以下のどれか1つでも当てはまったら、**その時点で発注してください。**

- [ ] 4週間の実測で、月の課金時間が **180時間**(1日6時間)を超えた
- [ ] **守秘義務の厳しい案件**が入り、外部クラウドが使いにくくなった
- [ ] RTX 5090の実勢価格が **¥550,000を下回った**
- [ ] RunPodを最適化した**あとでも**、「1本試すのにいくら」が頭をよぎって
      手が止まる状態が続いている

**4つ目がいちばん正当な理由です。** 数字ではありませんが、
百合子さんが最初に書かれた「安心して思う存分生成したい」に
まっすぐ対応するのはこれだけです。**自分でOKを出していい項目です。**

---

## 5. 私の予想と、推奨

**予想:** 品質テストは通ると思います(48GBのL40Sなら、ほぼ確実に。
32GBでも、seedを固定してプロンプトで細部を縛る百合子さんの書き方なら通る可能性が高い)。
そして**3ヶ月以内に、上の4条件のどれかが発火する**と思います。

**なので「いずれ買う」と思っておいて構いません。ただし今月ではない。**

### 推奨する進め方

| いつ | やること | かかるお金 |
|---|---|---|
| **今週** | Network Volume + GPU乗り換え + 品質テスト | **約¥2,000** |
| **今週〜4週間** | 台帳をつけながら普通に制作する | 月**約¥14,000** |
| **4週間後** | `h3log.py decide` を実行 + 上の4条件を確認 | ¥0 |
| **条件が発火したら** | 発注 | ¥1,060,000 |
| **3ヶ月経っても発火しなければ** | 買わなくていい。借りるが正解だった | ¥0 |

**この進め方の良いところは、「決断を先送りしている」のではなく
「決断の条件をいま決めてしまう」ことです。**
条件を決めた時点で、決断はもう終わっています。あとは発火を待つだけ。

---

## 6. お金の面での安心材料

念のため、数字を置いておきます。

- 年商 約700万円に対し、106万円の設備投資は **15%**。
  設備投資として**無理な比率ではありません**
- パソコンは通常**4年で減価償却**。年間約26.5万円が経費になります
  (※必ず顧問税理士に確認してください)
- **最悪のケースでも失敗になりません。** 買った後もRunPodは月0円で
  置いておけるので、「買ったけど足りなかった」ときは併用すればいい
- **買わなかった場合も損失ゼロ。** 月1.3万円で回り続けます

つまり **どちらを選んでも、致命的な失敗にはならない構造**です。
だから安心して、テスト結果に従ってください。

---

## 7. 今週の3ステップだけ覚えてください

1. **Network Volumeを付ける**(15分・月1,600円)
2. **L40Sと32GB相当で `C-2d` を作り比べる**(半日・約¥300)
3. **上のチェックリストで判定する**

**これで決断の9割が終わります。**
