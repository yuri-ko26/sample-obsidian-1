# Mac併用 ─ 推奨構成と運用

> 編集はMac、生成はWindows機。**この2台構成が、いちばん理にかなっています。**
> 製品の比較は [[07-ローカルPC-製品比較と見積もり]]、判断の枠組みは [[04-買うか借りるか-判断シート]]。

---

## いちばん安心してほしいこと

**Windowsをほとんど触らずに済みます。**

ComfyUIは**ブラウザで動く画面**です。だから生成PCは部屋の隅に置いたまま、
**Macのブラウザから操作**できます。画面もキーボードも、日常的には要りません。

```
生成PC（部屋の隅・画面なしでOK）
   ↓ 家のWi-Fi / LAN
Macのブラウザで  http://192.168.x.x:8188  を開く
   ↓
いつも通りのComfyUI画面。RunPodの時とまったく同じ操作
```

普段触るのは**いつものMacだけ**です。

### そして、ローカルにはメーターがありません

今日いちばん怖かったのは、**「$3.49/hrが回っている中で、慣れない操作をすること」**
だったと思います。

**買えば、それが消えます。**

|---|---|---|
| セットアップ中の課金 | かかる | **0円** |
| 失敗してやり直す | お金がかかる | **0円** |
| 途中でやめて明日にする | 課金が続く | **0円** |

**セットアップに3日かけても0円**です。今日感じた怖さは、構造的になくなります。

## 推奨構成

### ベース機：パソコン工房 LEVEL-M87B-144F-XKXB-Limited Edition [Memory Re]

**¥699,800（税込）**

| 項目 | 内容 | 評価 |
|---|---|---|
| GPU | **GeForce RTX 5090 Founders Edition（32GB）** | ⭐ 本命。H3の量子化版が丸ごと収まる |
| CPU | Core i5-14400F | 生成専用機なら**これで十分**（重い処理はGPUが担当） |
| 電源 | **1200W 80PLUS PLATINUM** | ⭐ 上位機より良い。増設不要 |
| マザー | B760 | — |
| メモリ | DDR5 **16GB**（認定再生メモリ） | ⚠️ **要増設** |
| SSD | 500GB | ⚠️ **要増設** |
| OS | Windows 11 Home | ブラウザ運用なので Home で問題なし |

> 💡 **「認定再生メモリ」**でコストを抑えたモデルです。だから同じRTX 5090搭載機でも
> 他社より10万〜17万円安くなっています。メモリは増設するので気にしなくて大丈夫です。

### 増設して、こうします

| 項目 | 内容 | 目安 |
|---|---|---|
| ベース機 | 上記 | ¥699,800 |
| **メモリ 64GB へ**（できれば128GB） | H3が必要とする | +¥35,000〜70,000 |
| **SSD 2TB 追加** | モデル50GB＋生成物置き場 | +¥25,000 |
| **合計** | | **約¥760,000〜795,000** |

> ⚠️ **メモリだけは絶対に削らないでください。** H3はVRAMに乗り切らない分を
> システムメモリに逃がします。16GBのままだと、**せっかくのRTX 5090が待たされる**か、
> 読み込みで落ちます。**最低64GB、余裕があれば128GB。**

### なぜ上位機（ドスパラ¥866,980など）にしないか

生成専用機なので、**CPUの差はほとんど効きません**。編集はMacでやるからです。
その差額（約10万円）は、**メモリとSSDに回した方が確実に効きます。**

## Mac と PC の連携（ここを設計しておくと快適です）

### ① 操作 ─ Macのブラウザから

PC側でComfyUIを起動する際、`--listen 0.0.0.0` を付けます（既に手順に入っています）。
あとはMacのSafariで `http://<PCのIPアドレス>:8188` を開くだけ。

**ブックマークしておけば、以後はワンクリック**です。

### ② 生成物の受け取り ─ 共有フォルダ

PC側の生成フォルダをネットワーク共有にして、Macから直接読みます。

1. Windows側で `C:\ComfyUI\output` を**共有フォルダ**に設定
2. Macの Finder で **⌘K** →  `smb://192.168.x.x` を入力 → ユーザー名とパスワード
3. マウントされたフォルダが、Macの普通のフォルダとして見える

**Premiereから直接読み込めます。** コピーの手間がなくなります。

> 💡 PCのIPアドレスは**固定**にしておいてください（ルーター設定 or Windows側で固定）。
> 変わるたびにブックマークを直す羽目になります。

### ③ 参照画像の渡し方

同じように、Mac側の素材フォルダを共有するか、
PC側に「入力用」の共有フォルダを1つ作って、そこにMacから放り込む形が簡単です。

### ④ 有線が使えるなら有線で

動画ファイルは大きいので、**両方とも有線LAN**が理想です。
Wi-Fiでも動きますが、10秒の動画1本でも待ち時間が変わります。

## 発注前に、お店に確認すること

**この3つだけ聞いてください。**（電話でもチャットでもOK）

1. **「このモデル、メモリは最大何GBまで積めますか？128GBは可能ですか？」**
   → B760マザーなのでスロット数の確認が必要です

2. **「BTOカスタマイズでメモリを64GB／128GBに変更した場合、いくらになりますか？」**
   → 後から自分で増設するより、最初から積んでもらう方が安全です

3. **「SSDを2TBに変更、または追加した場合の価格は？」**

> 💡 **「AI画像・動画生成に使います。メモリを多めに積みたい」**と伝えれば話が早いです。
> パソコン工房は店舗もあるので、**店頭で相談するのも手**です。

## 買った後も、RunPodは解約しないでください

| 状況 | 使うもの |
|---|---|
| 日常の制作・試行錯誤 | **ローカルPC**（無料・無制限・メーターなし） |
| 納期が重なって並列で回したい | RunPod を追加で立てる |
| PCが故障した | RunPod（**業務が止まらない**） |
| 長尺・高解像度で一時的にVRAMが要る | RunPodのH100 |

Network Volume（月$10.50 ≈ ¥1,600）だけ残しておけば、**いつでも数分で復帰**できます。
**これが「安心して制作に打ち込める環境」の完成形**だと思います。

## 進め方

### 急がなくて大丈夫です

**RTX 5090は定価¥393,800に対し、実勢が約2倍の品薄状態**です。
価格が落ち着けば**20万円以上安くなる可能性**があります。

案件はRunPodで凌ぎながら（→ [[06-GPUが空いたらこれをやる]]）、
**価格を見つつ決める**のが賢い進め方です。

### 買うと決めたら

- [ ] 上の3点をお店に確認する
- [ ] メモリ64GB以上・SSD 2TB以上で発注
- [ ] 届いたら、**時間をかけて**セットアップ（メーターは回りません）
- [ ] `C-2d` を生成して、H100版と画質を見比べる → [[04-買うか借りるか-判断シート]]

### 税務（要・税理士確認）

- パソコンは通常**4年で減価償却** → 年間約¥195,000が経費
- 年商700万円に対して約78万円は**11%程度**。設備投資として無理のない比率
- **必ず顧問税理士さんに確認してください**
