## いま何が起きているか

4日で110ドル。RunPodのH100 SXMは1時間あたり約3.29ドルなので、逆算すると:

| | |
|---|---|
| 課金された時間 | 約33時間(4日間) |
| 1日あたり | 約8.3時間、Podが動いていた |
| 月換算のペース | **約12.7万円/月** |

一方で、実際の生成にかかる時間はどれくらいか。H3で7〜10秒のカットを1本作るのに
かかるのは**2〜3分**です。仮に1日30本生成したとしても、実生成時間は**約1〜1.5時間**。

```
1日にお金を払っている時間   ████████████████████████████████  8.3時間
1日に実際に生成している時間  ████                              1.2時間
                            ↑ 残りの約85%は、考えている間・
                              プロンプトを書いている間・
                              できた動画を見返している間・
                              ダウンロードしている間の料金
```

**恐怖の正体はこれです。** 生成を我慢しても料金は下がりません。下がるのは
「Podを立てている時間」だけ。つまり、**我慢する方向の努力が効かない構造**に
なっていたということです。これは百合子さんの使い方の問題ではなく、設定の問題です。

さらに、`03-generated-videos/README.md` にご自身で書かれていた

> Runpod上のComfyUIは生成後にファイルが消えてしまうため

これが決定的です。**Network Volume(永続ストレージ)が付いていない状態**です。
だから毎回42.5GBのモデルを入れ直すところから始まり、その待ち時間にも課金され、
「せっかく立てたんだから消したくない」という気持ちになる。悪循環の入口でした。

## 打ち手は3つ。順番に効きます

| # | やること | 効果 | 難易度 |
|---|---|---|---|
| 1 | **Network Volumeを付ける** | 起動が30分→2分に。ファイルが消えない | 15分 |
| 2 | **GPUをH100 SXMから替える** | 時間単価が **1/3〜1/4** に | 30分 |
| 3 | **プロンプトはObsidianで書き、まとめて生成** | 課金時間が **1/3** に | 習慣 |

### 1. Network Volume(最優先・これが土台)

料金は **1GBあたり月0.07ドル**。150GB使っても**月10.5ドル(約1,600円)**です。
モデル・ComfyUI・生成物がPodを消しても残るので、

- 毎回のセットアップが消える
- **生成物が消えない**(いまダウンロードし忘れると失われている状態)
- 「消すのがもったいない」という気持ちがなくなる → 気軽に止められる

打ち手3が続けられるかどうかは、これが入っているかにかかっています。

### 2. GPUを替える

H3のオープンウェイトは42.5GB、量子化版(int8)なら **31.7GB**。つまり
**32GBのGPUに収まります**。80GBのH100 SXMは、この作品には積みすぎです。

| GPU | VRAM | 単価/時 | H100比 |
|---|---|---|---|
| H100 SXM(現在) | 80GB | $3.29 | — |
| L40S | 48GB | $0.86 | **1/3.8** |
| RTX 5090 | 32GB | $0.99 | **1/3.3** |
| RTX 4090 | 24GB | $0.69 | 1/4.8 |

RTX 5090での実測は、**10秒・864×480のカットで175秒**。H100より遅いとしても
せいぜい1.5〜2倍で、単価は3.3倍安い。**1本あたりの金額では確実に安くなります。**

> ⚠️ ただし量子化すると画質がわずかに変わる可能性があります。
> クライアント案件なので、**必ず見比べてから決めてください。**
> やり方は [[02-GPU比較とローカルPC構成案]] の「乗り換えテスト手順」に。
> 幸い `C2d_v1.mp4` という「H100で作った既知の正解」が手元にあるので、
> 同じプロンプト・同じ参照画像で作り比べれば一発で分かります。

**まずL40S(48GB)から試すのがおすすめです。** 48GBあれば量子化を弱められるので、
画質の変化がいちばん小さく、しかも5090より安い。

### 3. 「Podが動いている間は、生成だけ」

いちばん効くのに、お金がかからない打ち手です。

```
これまで:  Pod起動 → プロンプトを考える → 生成 → 見る → 直す → 生成 → ... → 停止
           └────────────── ぜんぶ課金 ──────────────┘

これから:  Obsidianでプロンプトを5〜10本書き溜める(無料・何時間かけてもいい)
              ↓
           Pod起動 → まとめて生成 → 全部ダウンロード → 停止
           └────── ここだけ課金 ──────┘
              ↓
           Obsidianで見返して、次の版を書く(無料)
```

百合子さんの `02-scenes-v2/` の書き方は、既にこの流れに完璧に合っています。
**プロンプトを練る作業と、生成する作業を、時間的に分けるだけ**です。

## で、PCは買うべきか

**実測データで判定できるようにしました。** `scripts/h3log.py` に記録を貯めると、
`decide` コマンドが答えを出します。いまの数字を入れるとこうなります。

### いまのまま(H100 SXM)を続けた場合

| | 月額 |
|---|---|
| 借りる | ¥127,488 |
| 買う(実勢106万円を4年償却+電気代) | ¥28,283 |

損益分岐点 **月55時間(1日1.8時間)**。現在は月250時間ペース。
→ **買った方が圧倒的に安い。年間119万円の差。**

### 打ち手2だけやって、L40Sに替えた場合

| | 月額 |
|---|---|
| 借りる | ¥44,434 |
| 買う(同上) | ¥30,350 |

損益分岐点 **月228時間(1日7.6時間)**。
→ いまのペース(月333時間)なら、まだ買った方が安い(年間17万円差)。

### 打ち手3までやった場合(★目標地点)

課金時間が1日2.5時間まで落ちると:

| | 月額 |
|---|---|
| 借りる | **¥13,330** |
| 買う | ¥24,563 |

→ **費用だけで見れば、借りる方が月1.1万円安くなります。**

### だから、こう考えてください

**「安くするために買う」のではなく、「別の2つを買う」**のだと思います。

1. **クライアント情報が、一歩も外に出ない**
   ローカルなら、キャラクター設定も未公開の絵コンテも、事務所の外に出ません。
   守秘義務のある案件では、これは値段以上の意味があります。
   → 詳細は [[03-クライアント情報とライセンス]]

2. **メーターが止まる**
   百合子さんが書かれた「膨大なコストがかかってくる恐怖から解放されたい」に、
   まっすぐ効くのはこれだけです。借りている限り、たとえ月1.5万円でも
   「いま1本試すといくら」は頭から消えません。買えば**限界費用がゼロ**になり、
   「もう1回だけ試してみよう」が無料になります。作品の質は、たいてい
   その「もう1回」から生まれます。

**差額は月わずか¥11,233。**この金額で上の2つを買う。**それは高くない**というのが私の意見です。
ただし**急いで決める必要はありません。**打ち手1〜3をやれば恐怖は今週消えるので、
落ち着いて2〜4週間の実測を見てから決められます。

## ロードマップ

### Phase 0 ─ 今週(止血)

- [ ] Network Volumeを作成してPodに接続する(150GB)
- [ ] L40S 48GB で `C2d` を再生成し、`C2d_v1.mp4` と見比べる
- [ ] 問題なければ、以後のPodはL40Sで立てる
- [ ] Pod起動/停止のたびに `h3log.py pod start` / `pod end` を実行する
- [ ] 過去4日ぶんを `h3log.py pod add` でざっくり遡って入れる

→ **これだけで月12.7万円ペースが止まります。**

### Phase 1 ─ 2〜4週間(実測)

- [ ] 生成のたびに `h3log.py gen add` で1行記録する
- [ ] プロンプト本文は今まで通り `02-scenes-v2/` のノートに版で残す
- [ ] `h3log.py report` で、案件ごとの原価が出ることを確認する

→ **この期間で「勘」が「数字」になります。**

### Phase 2 ─ 数字が出たら(判断)

- [ ] `h3log.py decide` を実行する
- [ ] 出た分岐点と、上の「別の2つ」を並べて購入を決める
- [ ] 買う場合の構成と見積もりは [[02-GPU比較とローカルPC構成案]]
