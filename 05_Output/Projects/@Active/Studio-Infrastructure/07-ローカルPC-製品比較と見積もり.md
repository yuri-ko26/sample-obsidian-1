# ローカルPC ─ 製品比較と見積もり

> ✅ **Mac併用と決まりました。最終的な推奨構成は → [[08-Mac併用の推奨構成と運用]]**

> 調査時点: 2026年9月。**GPUは品薄で価格変動が激しい**ため、発注前に必ず現在価格を確認してください。
> 判断の枠組みは [[04-買うか借りるか-判断シート]]、背景は [[02-GPU比較とローカルPC構成案]] に。

---

## 先に、3つの結論

### ① BTO（メーカー完成品）が、自作より安いです

品薄でGPU単体が高騰しているため、**BTOメーカーの方が安くGPUを確保できています。**
「自作より20万円以上安い例」も出ている状況です。

**自作は考えなくて大丈夫です。** 保証もサポートも付いて安いなら、BTO一択です。
百合子さんがパーツを選んだり組んだりする必要はありません。

### ② Mac は今回は選択肢から外してください

| 処理 | Mac (M5 Max) | RTX 5090 |
|---|---|---|
| SD 3.5 Large 画像生成 | 約90秒 | **約18秒**（**5倍速い**） |
| 動画生成全般 | — | **2〜5倍速い** |

理由は速度だけではありません。**ComfyUIのカスタムノード・LoRA・拡張は、
ほぼすべてCUDA（NVIDIA）優先で作られています。** Macだと動かないもの、
遅いものが常につきまといます。H3のような最新モデルでは特にそうです。

> 💡 編集用のMacをお持ちなら、そちらはそのまま使い続けて、
> **生成用にWindows機を1台足す**のが現実的です。

### ③ いまの使い方なら、どの価格帯でも「買う」が安い

実測（7日で30.4時間＝月130時間ペース、H100 SXM $3.49/hr）で計算すると：

| PC価格 | 買う（月額換算） | 借りる（現状） | 損益分岐点 | 年間差額 |
|---|---|---|---|---|
| ¥750,000 | ¥18,856 | ¥66,439 | 月37時間 | **¥571,000** |
| **¥900,000** | **¥21,981** | ¥66,439 | 月43時間 | **¥533,000** |
| ¥1,200,000 | ¥28,231 | ¥66,439 | 月55時間 | ¥458,000 |
| ¥2,300,000 | ¥51,148 | ¥66,439 | 月100時間 | ¥183,000 |

**現在の稼働は月130時間。どの価格帯でも分岐点を超えています。**

> ⚠️ ただしこれは「H100 SXM（¥510/時）を使い続けた場合」との比較です。
> 安いGPUに移れれば借りる方が安くなります。**でも今日、その安いGPUは
> 在庫が無くて使えませんでした。** それが現実です。

## 選択肢

### ⭐ A案 ─ RTX 5090（32GB）BTO 【推奨】

H3の量子化版（31.7GB）が**VRAMに完全に収まる**構成。実測で
10秒・864×480のカットを**175秒**、15秒1080p（VSR併用）を**314秒**。

**具体的な候補（2026年9月時点）**

| 販売店 | 型番 | 構成 | 価格 |
|---|---|---|---|
| パソコン工房 | LEVEL-M87B-144F-XK1XW Limited | Core i5-14400F / RTX 5090 / **16GB** / 500GB / 1000W | **¥749,800** |
| ドスパラ | GALLERIA XPC7A-R59-WL | Core Ultra 7 265F / RTX 5090 / **16GB** / 1TB | **¥866,980** |
| マウスコンピューター | クリエイター向けWS | 構成充実（メモリ・SSD最初から多め） | ¥1,070,000〜1,500,000 |

> ⚠️ **上2つはメモリが16GBしかありません。これは必ず増やしてください。**
> H3はVRAMに乗り切らない分をシステムRAMに逃がすので、**16GBだと
> せっかくのGPUが待たされます**（最悪、読み込みで落ちます）。

**現実的な見積もり**

| 項目 | 金額 |
|---|---|
| ドスパラ GALLERIA XPC7A-R59-WL | ¥866,980 |
| メモリ 128GB へ増設（BTOオプション or 後付け） | +¥60,000〜80,000 |
| SSD 追加 4TB（素材置き場） | +¥40,000 |
| **合計** | **約¥970,000** |

**メモリを64GBに抑えれば ¥930,000 前後**まで下がります。H3は64GBでも動きます。

**H3以外の恩恵（これが地味に大きい）**
- **After Effects のレンダリングが劇的に速くなる**
- **Premiere Pro で4K素材がリアルタイム再生できる**
- 書き出し時間が短縮 → 修正の回転が速くなる

つまり **H3のためだけの投資ではありません。** 制作業務全体が速くなります。

---

### B案 ─ RTX 4090（24GB）【非推奨】

| | |
|---|---|
| 新品 | 約¥370,000（流通わずか） |
| 中古 | 約¥380,000〜420,000 |

**おすすめしない理由：**
- **2024年秋に生産終了**。中古相場が高騰し、**新品と中古の値差がほとんどない**
- **24GBは手狭**。強めの量子化が必要になり、**キャラクターの一貫性が崩れやすい**
- 5090との価格差（約30万円）に対して、VRAM 8GB差・世代差は割に合わない

百合子さんの作品は「たまちゃんに眉毛が生えない」「ぽよんの口が開きすぎない」といった
**細部の一貫性が命**です。ここを削るのは勧めません。

---

### C案 ─ RTX PRO 6000 Blackwell（96GB）【いまは過剰】

| | |
|---|---|
| カード単体 | 約¥2,200,000 |
| ワークステーション構成 | 約¥2,300,000〜 |

**できること：** 量子化なし（BF16）で動く。長尺・高解像度に強い。複数案件の並列処理。

**でも今は不要です。** RTX 5090の3倍以上の価格に対して、速度差は**10〜15%程度**。
年商700万円の規模では、**年商の33%を1台に投じる**ことになります。

> 💡 将来、大きな案件が継続的に入るようになったら、その時に検討すれば十分間に合います。

---

### D案 ─ Mac Studio 【除外】

上記②の通り、**動画生成では2〜5倍遅く、エコシステムも不利**です。
編集用としては優秀ですが、**H3の生成機としては選ばないでください。**

### E案 ─ 買わずにRunPodを続ける

| | |
|---|---|
| H100 SXMのまま | 月¥66,439 |
| 安いGPUに移れたら | 月¥10,000〜15,000 |

**問題は「安いGPUに移れるか」です。** 今日の調査結果：

- 日本（AP-JP-1）には **H100 SXM と H200 SXM しかない**
- 安い48GBカードは **EU・米国中心**＝**H3のライセンス除外地域**
- カナダ（適用地域内）にもあるが、**在庫が数分単位で出たり消えたり**

**つまり「安く借りる」は、運とタイミング次第です。**

## 判断のポイント

### 費用で見ると

**買う方が年間45〜57万円安い**（現在の使い方が続く前提）。
¥900,000の投資は**約1年5ヶ月で回収**できる計算です。

### 費用以外で見ると（こちらが本題かもしれません）

百合子さんが最初に書かれていたことに、まっすぐ効くのはこちらです。

> 膨大なコストがかかってくる恐怖から、安心して思う存分生成することができ
> 最高の作品が残せるようにしたい

**買うと、こうなります：**

| | 借りる | 買う |
|---|---|---|
| 1本生成するたびの費用 | かかる | **ゼロ** |
| 「もう1回試そう」 | ためらう | **無料** |
| GPUの空き待ち | **あり**（今日それで進めなかった） | なし |
| クライアント情報 | 外部クラウドへ | **事務所から出ない** |
| 起動までの時間 | 5〜15分 | **すぐ** |

**今日、GPUが取れずに作業できませんでした。** これは百合子さんのせいでは
ありませんが、**買えば二度と起きません。** 「安心して制作に打ち込める環境」という
目標から見ると、この差は金額以上の意味があります。

## 買う前に確認したいこと

| # | 確認事項 | なぜ |
|---|---|---|
| 1 | **いま編集に使っているPCはMac？Windows？** | Macなら「生成用に1台追加」になります。Windowsなら買い替えで一本化できます |
| 2 | **置く場所と電源** | RTX 5090機は**1000W級**。専用コンセント推奨。夏場は室温も上がります |
| 3 | **音** | 生成中はファンが回ります。**録音する部屋には置かない**方が無難です |
| 4 | **キャッシュフロー** | 一括かローンか。年商700万に対し約90万は**約13%**。無理な比率ではありません |
| 5 | **税務** | パソコンは通常**4年で減価償却**（年間約23万円が経費）。**必ず税理士さんに確認を** |

## おすすめの進め方

### 今すぐ（無料）

- [ ] 上の「確認したいこと」1〜4に答えを出す
- [ ] ドスパラ・パソコン工房・マウスの**現在価格を見る**（毎週変動します）
- [ ] **RTX 5090の実勢価格が下がっていないか**チェック（定価は¥393,800。いまは約2倍）

### 買うと決めたら

- [ ] **メモリは必ず64GB以上、できれば128GB**（ここは絶対に削らない）
- [ ] 電源1000W以上
- [ ] SSDは2TB以上（素材用に別途4TBあると安心）
- [ ] BTOの**保証・サポート内容**を確認（自作しない最大の理由がここ）

### 買った後も

**RunPodは解約しないでください。** Network Volumeだけ月¥1,600残しておけば：

- 納期が重なった時に**並列で回せる**
- PCが故障しても**業務が止まらない**
- 長尺・高解像度で一時的にVRAMが要る時の逃げ場になる

**これが「安心して制作に打ち込める環境」の完成形**だと思います。
