# いますぐやるRunPodコスト削減(所要45分)

> 上から順にやれば終わります。**この45分で、月12.7万円ペースが止まります。**
> 全体の考え方は [[00-結論とロードマップ]] にあります。
>
> 🔧 **実際に画面を見ながら作業するときは → [[05-RunPod作業手順書]]**
> (RunPodのどこを押すか、どのコマンドを打つかまで書いてあります)

---

## STEP 1 ─ まず現実の数字を確認する(5分)

私の計算は「4日で110ドル ÷ H100 SXMの単価3.29ドル」からの逆算です。
**実際の請求と食い違っていないか、先に確認してください。**

1. RunPod → **Billing** → 使用履歴を開く
2. 見るところ:
   - どのGPUを、何時間動かしたことになっているか
   - ストレージ料金が別に発生していないか

> 💡 もし「思っていたより長い時間」動いていたら、**停め忘れ**があります。
> 「思っていたより短い」なら、単価がもっと高いGPU構成かもしれません。
> どちらでも、次のSTEPの効果は変わりません。

---

## STEP 2 ─ Network Volumeを作る(15分)★最重要

いま**永続ストレージが付いていない**状態です。だから生成した動画が消え、
毎回42.5GBのモデルを入れ直しています。**その待ち時間にも課金されています。**

### 手順

1. RunPod → **Storage** → **Network Volumes** → **+ New Network Volume**
2. 設定
   - **Datacenter**: これから使うGPUが在庫にあるリージョンを選ぶ
     ⚠️ **Network Volumeは同じデータセンター内のPodにしか付けられません。**
     先にGPUの在庫があるリージョンを確認してから作ってください。
   - **Size**: **150GB**(モデル42.5GB + ComfyUI + 生成物の余裕)
   - **Name**: `h3-studio` など分かる名前
3. 料金: **1GB あたり月0.07ドル** → 150GBで **月10.5ドル(約1,600円)**

### Podを立て直す

4. **Pods** → **Deploy** → GPUを選ぶ画面で
   **"Network Volume" の欄に、いま作ったボリュームを指定**する
5. 起動後、ボリュームは通常 **`/workspace`** にマウントされます
6. **ComfyUIとモデルを `/workspace` の下にインストールし直す**
   ここが肝心です。`/workspace` の外に入れると、また消えます。

```
/workspace/                 ← ここに入れたものだけが残る
├── ComfyUI/
│   ├── models/             ← H3のモデル(42.5GB)はここ
│   └── output/             ← 生成物はここ。もう消えない
└── ...
```

7. 一度セットアップしたら、**Podを消してもボリュームは残ります。**
   次回は同じボリュームを付けたPodを立てるだけで、**2分で作業開始**できます。

> ✅ これが効いた合図:2回目にPodを立てたとき、モデルのダウンロードが
> 走らずにすぐComfyUIが開けば成功です。

## STEP 3 ─ GPUを乗り換える(20分)

H3のオープンウェイトは**32GBのGPUに収まります**。80GBのH100 SXMは過剰です。

### 乗り換えテスト手順

**いきなり全部替えないでください。**1カットだけ作り比べて、画質を確認します。
幸い、比較の基準になる「H100で作った既知の正解」が手元にあります。

1. 比較の基準を決める
   - 対象: **`C-2d` v1**(プロンプト:
     `02-scenes-v2/C2d-tamachan-running-start-bump.md`)
   - 正解: `03-generated-videos/C2d_v1.mp4`(H100 SXM・bf16 で生成済み)

2. **L40S 48GB**($0.86/hr)でPodを立てる ← まずここから
   - 48GBあれば量子化を弱められるので、**画質の変化がいちばん小さい**

3. まったく同じプロンプト・同じ参照画像・**同じseed**で生成する

4. `C2d_v1.mp4` と並べて見比べる。見るポイントは百合子さんが
   `character-reference.md` で厳しく指定されている箇所です:
   - [ ] たまちゃんに眉毛が生えていないか
   - [ ] ぽよんの口が開きすぎていないか、輪郭線だけを保っているか
   - [ ] ぽよんの中のガムボール・紙吹雪がこぼれていないか
   - [ ] 接触時にぽよんが丸みを保っているか
   - [ ] 顔の崩れ・色味のズレがないか

5. 判定
   - **問題なし** → 以後はL40Sで運用。**時間単価が1/3.8に**
   - **微妙に崩れる** → RTX 5090($0.99)でも試す。それでもダメなら
     H100 PCIe($2.89)へ。それでも現状より安い
   - **明確に劣る** → H100のまま。ただしSTEP 2と4は必ず効くので続行

6. 結果を記録する

```bash
python3 scripts/h3log.py gen add \
  --project H3-Video-Series --cut C-2d --version "v1-L40S検証" \
  --mode I2VA --quant int8 --gpu "L40S" --rate 0.86 \
  --compute-s 200 --video C2d_v1_L40S.mp4 --verdict OK \
  --note "H100版と比較。眉毛なし・口の開きOK・ガムボール保持OK"
```

## STEP 4 ─ 「Podが動いている間は、生成だけ」(習慣)

お金がかからないのに、いちばん効く打ち手です。

### Podを立てる前に

- [ ] Obsidianで**5〜10本ぶんのプロンプトを書き終えている**
- [ ] 参照画像はすべて用意できている
- [ ] 「今日の生成リスト」が決まっている

### Podを立てたら

```bash
# 起動した瞬間に実行(時間の記録が始まります)
python3 scripts/h3log.py pod start \
  --project H3-Video-Series --gpu "L40S" --rate 0.86
```

- リストを上から**淡々と生成するだけ**
- **見返さない。悩まない。直さない。**それは停めてからやる作業です
- 全部終わったら、**生成物を必ずダウンロード**する
  (Network Volumeを付けたので消えませんが、手元にも残す)

### 停めたら

```bash
python3 scripts/h3log.py pod end
```

そのあと、Obsidianで落ち着いて見返し、次の版のプロンプトを書きます。
**ここは何時間かけても無料です。**

> 💡 停め忘れ防止:`pod start` を実行したら、スマホのタイマーも
> 一緒にセットしておくと確実です。

## STEP 5 ─ 過去4日ぶんを台帳に入れる(5分)

判断材料にするため、いままでの実績もざっくり入れておきます。
**正確でなくて構いません。**日ごとの「だいたい何時間動かしたか」で十分です。

```bash
cd ~/sample-obsidian-1   # vaultのパスに読み替えてください

python3 scripts/h3log.py pod add --project H3-Video-Series \
  --gpu "H100 SXM" --rate 3.29 --start "2026-09-06T10:00" --minutes 500
python3 scripts/h3log.py pod add --project H3-Video-Series \
  --gpu "H100 SXM" --rate 3.29 --start "2026-09-07T10:00" --minutes 500
# …日数ぶん繰り返す
```

## 効果の見込み

| | 現状 | STEP 2+3 のあと | STEP 4 まで |
|---|---|---|---|
| 時間単価 | $3.29 | $0.86 | $0.86 |
| 課金時間/日 | 8.3時間 | 8.3時間 | **2〜3時間** |
| **月額** | **約12.7万円** | 約3.3万円 | **約1.2万円** |

ストレージ代(月1,600円)を足しても、**月12.7万円 → 月1.4万円**。
**約90%減**です。
