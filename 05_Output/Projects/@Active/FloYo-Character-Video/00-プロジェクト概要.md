# 🎯 Project: FloYoによるクライアントオリジナルキャラクター動画生成

## 📌 Executive Summary
**一行説明**: FloyoのComfyUIホスト環境上でMiniMax H3を実行し、クライアントのオリジナルキャラクターを用いた動画を、学習非利用・説明責任・監査対応の条件を満たしながら制作する。

**プロジェクトの目的**: クライアントから提示された5つの確認観点(下記)をすべて満たした状態で、商用動画生成を開始できる環境を整備する。

**想定成果**: Floyo Enterprise不要・個人クリエイター規模のプランで運用可能な、学習非利用が担保された動画生成パイプラインと、説明責任・監査対応のための制作ログ運用。

## 🔒 クライアント確認観点(必達条件)
1. LLMに学習されない設定となること
2. ログ取得可能で説明責任が果たせること(取得不可の場合はプロンプト自己保存で代替)
3. 監査・調査が必要な時に生成AI提供元から情報開示対応ができること
4. 生成AI提供者のサービス利用に使われないこと
5. AIで作成された生成物が自社利用の範囲で使用できること

→ 各項目の詳細な根拠・対応方法は [[02-クライアント確認事項チェックリスト]] を参照。

## 🧩 採用構成(技術方針)

| 項目 | 内容 |
|---|---|
| プラットフォーム | Floyo(floyo.ai) — ブラウザ完結のクラウドComfyUI |
| 実行モデル | MiniMax H3(Hailuo 3.0) — **Floyoホスト実行(セルフホスト型ノード)限定** |
| 禁止事項 | MiniMax外部APIノードの使用(2K化・音声同期機能含む)は本案件では不使用 |
| 想定プラン | Explorer($12/月)〜Trailblazer($56/月)、生成量に応じて選択。Enterpriseは不要 |
| ログ運用 | Floyo Run History + 自己保存ログ(03-制作ログ/)の二重運用 |

## ⚠️ 実行環境に関する重要な注意

Floyoは**ローカルにインストールするソフトウェアではなく、ブラウザから利用するクラウドSaaS**です。そのため「ライブラリ/依存パッケージのインストール」に相当する作業は発生しません(Floyo自身が謳う "zero setup, no Docker, no GPU management" の通りです)。今日から生成を開始するために必要なのは以下の3点のみです。

1. floyo.aiのアカウント(メールアドレス・支払い方法)
2. ブラウザ(Chrome推奨)
3. クライアントのキャラクター参照素材(画像・設定資料)

**この作業環境(Claude Code)からはfloyo.aiへの直接アクセス・アカウント作成・決済操作・実際の生成実行はできません。** floyo.aiは外部の有償SaaSであり、サインアップ・支払い・ブラウザでのワークフロー操作はご本人が行う必要があるためです(この制約は権限設定の問題ではなく、外部サービスへのアカウント作成・決済を代行する手段がこの環境に無いことによるものです)。

そのため、今回は以下を用意しました。
- [[01-環境構築手順書]] — あなたが今日ご自身のブラウザで実行する、Step by Stepの手順書(所要目安20〜30分)
- [[02-クライアント確認事項チェックリスト]] — 5条件それぞれの根拠と、集めるべき証跡の一覧
- `03-制作ログ/` — 生成のたびに記録する制作ログ(説明責任・監査対応の一次資料)
- `04-エビデンス/` — Trust Center・規約・サポート回答等のスクリーンショット保管先

手順書に沿って進めれば、今日中にテスト生成の完了まで到達できます。
