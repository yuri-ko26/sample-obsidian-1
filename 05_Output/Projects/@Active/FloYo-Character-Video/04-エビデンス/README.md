# 04-エビデンス

このフォルダには、クライアント確認事項(②説明責任・③監査対応)のための証跡を保存します。

## 保存するもの
- Trust Center「Verified Private」確認画面のスクリーンショット
- Floyo Run History(実行履歴)のスクリーンショット
- Floyoサポートとの監査対応確認のやり取り(メール等)
- Floyo利用規約・MiniMax H3ライセンスの該当箇所のスクリーンショット

## ファイル名の付け方
`YYYY-MM-DD_内容.png`(例: `2026-08-30_TrustCenter_MiniMaxH3.png`)

規約やTrust Centerの表示内容は将来更新される可能性があるため、**案件開始時点のスクリーンショットを必ず残してください**。
