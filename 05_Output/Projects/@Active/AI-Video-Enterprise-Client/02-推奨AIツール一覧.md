# 推奨AIツール一覧（要確認前提）

> **重要**: 下表は選定の出発点です。各社の規約・プラン内容は変更が多いため、**契約直前に必ず公式のToS/DPA/Trust Centerを再確認**してください。「◯」は執筆時点で一般的にBusiness/Enterprise/API契約に期待できる水準を示すもので、個別契約内容を保証するものではありません。

## 用途別カテゴリ

| カテゴリ | 用途 | 検討候補（Business/Enterprise/API契約前提） | Free/個人プランで避けるべき理由 |
|---|---|---|---|
| LLM（台本・プロンプト設計） | シナリオ、字幕文案、プロンプト生成 | Claude (Team/Enterprise)、Azure OpenAI Service、ChatGPT Team/Enterprise | 個人向けFree/Plusは「モデル改善への利用」がデフォルトで有効な場合があり、都度オプトアウト操作が必要 |
| 画像生成 | サムネイル、参照画像、静止カット | Adobe Firefly (Enterprise) | 個人向け無料枠は商用利用制限・コミュニティ投稿が既定ONの場合あり |
| 動画生成 | メイン映像生成 | Runway (Business/Enterprise)、Google Veo (Vertex AI経由)、Adobe Firefly Video (Enterprise) | Free/Proプラン、Kling/Pika等の個人向けプランはコミュニティギャラリー投稿や学習利用のオプトアウトが不十分な場合が多い |
| 音声・ナレーション | ナレーション、SE | ElevenLabs (Business) | 個人プランは音声データの2次利用範囲が広い場合がある |
| 編集・仕上げ | 最終編集、合成 | Adobe Premiere Pro / DaVinci Resolve（ローカル処理） | クラウドAI処理を最終工程に持ち込むと、露出面（データが外部に渡る箇所）が増える |

## 確認観点テンプレート（ツールごとに埋める）

新規ツールを検討する際は、以下をベンダーの公式ドキュメント・営業窓口で確認し記録すること。

```
### [ツール名]
- 契約プラン: 
- モデル学習への不使用: 明記あり/なし（該当条項の引用）
- コミュニティ投稿等のデフォルト設定: ON/OFF、オプトアウト手順
- 生成物の権利帰属: 
- 商用利用可否: 
- IP侵害補償: あり/なし
- データ保持期間: 
- 第三者保証（SOC2/ISO27001等）: 
- 監査・情報開示対応の契約上の位置づけ: 
- 確認日 / 確認方法（規約URL・営業担当への確認メール等）:
```

## 個人クリエイターが直面する限界

- 多くのベンダーで「真のEnterprise契約」（DPA個別交渉、監査条項付き）は法人・一定契約規模が前提となっており、個人事業主単体では利用できるプランがBusiness/Teamレベルに留まることが多い
- この場合、[[01-コンプライアンス環境構築ガイド]] の「3. 監査・調査対応」に記載した代替策（第三者保証資料の提示、自己ログでの一次対応）で補う
- クライアントが特に条件③（監査対応）を厳格に求める場合、クライアント自身が対象ツールとエンタープライズ契約を締結し、そのアカウント内で自分が制作を行う体制も選択肢として提示する
