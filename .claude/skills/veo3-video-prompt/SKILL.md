# Veo 3.1 動画生成プロンプトガイド

Veo 3.1向けのプロンプトを作る・直す・レビューするときは、必ずこのガイドの型と語彙を使うこと。Veo
はプロンプトの言葉を映画のカット割りとして解釈するので、曖昧な形容詞の羅列ではなく、
「カメラが何を、どう写すか」を監督のように具体的に指示することが結果の質を大きく左右する。

## Veo 3.1がどんなモデルか(前提知識)

- 解像度: 720p / 1080p、アスペクト比: 16:9(横) / 9:16(縦)、長さ: 4秒 / 6秒 / 8秒
- **映像と同時に音声も生成する**(セリフ・環境音・SFX・BGM)。Veo2以前と違い、音を明示的に書き込むと動画に反映される
- 参照画像を使った「Ingredients to Video(素材/Footage機能)」で、複数ショットにまたがるキャラクターや場所の一貫性を保てる
- 「最初と最後のフレーム」指定でシームレスなトランジション(音声込み)を生成できる
- SynthIDによる電子透かしが自動付与される

## 基本公式:5つの要素を積み上げる

1本のプロンプトは、次の5要素を順番に積み上げて書く。要素を省略するとVeoが自由に補完してしまい、
狙った画にならないことが多い。

```
[映像/カメラワーク] + [被写体] + [アクション] + [コンテキスト(場所・時間・光)] + [スタイルと雰囲気]
```

| 要素 | 説明 | 例 |
|---|---|---|
| 映像 | ショットの種類・カメラの動き | クレーンショット、上半身のショット、主観ショット |
| 被写体 | 主人公・焦点となる要素 | 疲れた会社員、古い型のマイク、霧の中のハイカー |
| アクション | 被写体が何をしているか | こめかみを揉む、歌う、峡谷の縁に立つ |
| コンテキスト | 周囲・背景・時間帯・光源 | 散らかったオフィス、夜遅く、蛍光灯の冷たい光 |
| スタイルと雰囲気 | 美観・ムード・撮影手法 | レトロ、1980年代カラーフィルム風、粒子感 |

**完全な例**:
```
上半身のショット。疲れた会社員が、夜遅くに散らかったオフィスで、1980年代の大きなコンピュータの
前でこめかみを揉んでいる。シーンは、上からの蛍光灯の冷たい光と、モノクロモニターの緑色の光で
照らされている。レトロな雰囲気。1980年代のカラーフィルムで撮影したかのような、少し粒子感の
ある映像。
```

### 書き方の鉄則

- **フレーミング(ショットの種類)は文頭に置く**。「クローズアップで…」のように先頭で構図を宣言すると、
  Veoはその構図を最優先で反映する。
- **「beautiful」「amazing」「素晴らしい」のような漠然とした形容詞だけでは動かない**。
  「プロヴァンスのラベンダー畑にゴールデンアワーの光が差す」のように、場所・時間帯・光の
  条件まで具体的に書く。
- 1文が長くなりすぎたら、後述の「タイムスタンプ演出」で複数カットに分割する。

## カメラワークの語彙(映像言語)

具体的な映画用語を使うほど狙った画に近づく。以下を組み合わせて使う。

**カメラの動き**: ドリーショット / トラッキングショット / クレーンショット / 空撮 /
スローパン / 主観ショット(POV)

**構図(フレーミング)**: ワイドショット / クローズアップ / エクストリームクローズアップ /
ローアングル / ハイアングル / ツーショット

**レンズ・フォーカス**: 浅い被写界深度(shallow depth of field) / 広角レンズ / ソフトフォーカス /
マクロレンズ / ディープフォーカス

**カメラの動きの例**:
```
クレーンショット。ハイカーの低い位置から始まり、視点がずっと上に動いて、日の出時に巨大な霧の
峡谷の端に立っていることがわかる。
```

**浅い被写界深度の例**:
```
非常に浅い被写界深度でのクローズアップ。若い女性がバスの窓から、行きすぎる街の灯りを見ている。
窓ガラスには女性の姿がかすかに映っている。窓の外は夜の嵐。メランコリックな雰囲気をクールな
青いトーンで演出する。ムーディーで映画のような動画。
```

## サウンドの指定(Veo3.1の要)

Veo3.1は映像と音を同時生成するため、音を書かないと無音や意図しないBGMになりやすい。
種類ごとに書き分ける。

- **セリフ**: 鍵カッコで具体的なセリフを指定する
  ```
  女性が「もう行かなくちゃ」と言います。
  探偵が疲れた声で「この街の数ある事務所の中で、よりによって私の事務所に足を踏み入れるとは」
  と言います。
  ```
- **効果音(SFX)**: 「SFX:」または「効果音:」と明記する
  ```
  SFX: 遠くで雷が鳴る
  SFX: 茂った葉のざわめき、珍しい鳥の鳴き声が遠くで聞こえる
  効果音: 穏やかなオーケストラ曲が徐々に盛り上がりながら演奏される
  ```
- **環境音**: 「周囲の音:」でバックグラウンドのサウンドスケープを指定する
  ```
  周囲の音: 宇宙船ブリッジの静かなハム音
  ```

## ネガティブプロンプト:「〜なし」ではなく「何があるか」で書く

Veoは一般的な否定表現("no ...")をうまく処理できないことが多い。除外したいものは、
**その代わりに何が存在するシーンなのか**を肯定文で描写する。

❌ 悪い例: `人工構造物なし`
✅ 良い例: `建物や道路のない荒涼とした風景`

## 応用テクニック

### 1. タイムスタンプ演出(1本で複数ショットの完全なシーンを作る)

`[HH:MM-HH:MM] シーン説明` の書式で、1つの生成の中に複数カットを時系列で並べられる。
長い物語や複雑な演出をしたいときに使う。

```
[00:00-00:02] 革製のショルダーバッグをかけて、茶色のボサボサの髪をポニーテールにした若い女性
探検家の上半身を後ろから見た画像で、ジャングルの中で大きな木のつるをかき分けると隠れた道が
見つかる。

[00:02-00:04] 今度は探検家を正面から捉え、苔むした古代の遺跡を背景に、そばかすだらけの顔が
畏敬の念を抱いた表情でそれを見つめている。効果音: 茂った葉のざわめき、珍しい鳥の鳴き声が遠く
で聞こえる。

[00:04-00:06] 探検家が空き地に足を踏み入れ、崩れかけた石壁の細かな彫刻に手を触れる様子を
追うトラッキングショット。感情: 驚きと畏敬の念。

[00:06-00:08] 広角のハイアングルクレーンショット。ジャングルに半分飲み込まれた、広大な忘れ
去られた寺院跡の中央に、探検家が一人小さく立っている。効果音: 穏やかなオーケストラ曲が徐々に
盛り上がりながら演奏される。
```

### 2. 最初と最後のフレーム(トランジション)

2枚の参照画像(開始フレーム・終了フレーム)を与えて、その間をVeoに音声込みでつながせる手法。
`Ingredients to Video`(画像生成)と組み合わせて使う。

```
カメラは、歌手を正面から捉えた映像から始まり、歌手の周りを円を描くようにスムーズに180度
回転して、ステージ上の歌手を後ろから捉えた映像で終わる。「あなたに瞳を見つめられると、
何百万もの星が見えるみたい」と歌っています。
```

### 3. 動画素材(Footage/Ingredients to Video)で複数ショットの一貫性を保つ

キャラクター・場所の参照画像を用意し、それを使って複数のショットを生成すると、
会話シーンなどで人物・背景の一貫性が保たれる。同じ参照画像セットを使い回してショットごとに
プロンプトを分ける。

```
探偵、女性、オフィスでの場面設定の画像を使用して、探偵がデスクの後ろにいる上半身のショットを
作成してください。探偵は女性を見上げ、疲れた声で「この街の数ある事務所の中で、よりによって
私の事務所に足を踏み入れるとは」と言います。
```
```
探偵、女性、オフィスでの場面設定の画像を使用して、女性に焦点を当てたショットを作成してください。
彼女は少し不思議な笑みを浮かべながら、「あなたは高く推薦されているんですよ」と答えます。
```

## プロンプト作成時のチェックリスト

作業する際は、依頼された内容を上記の5要素(映像・被写体・アクション・コンテキスト・スタイル)
に分解し、抜けている要素をユーザーに確認するか、常識的に補って明示すること。特に:

- [ ] ショットの種類・カメラワークを文頭で宣言したか
- [ ] 場所・時間帯・光の条件を具体的に書いたか(漠然とした形容詞だけになっていないか)
- [ ] セリフ・SFX・環境音のうち、そのシーンに必要なものを明示したか
- [ ] 複雑な話の流れなら、タイムスタンプで複数カットに分割したか
- [ ] 複数ショットで同じキャラクター/場所を使うなら、参照画像(Footage)の利用を提案したか
- [ ] 除外したい要素は「〜なし」ではなく、代わりに存在するものとして肯定文で書いたか
- [ ] 尺(4/6/8秒)とアスペクト比(16:9 or 9:16)がこの用途に合っているか確認したか

## よくある失敗と直し方

| 失敗パターン | 直し方 |
|---|---|
| 「美しい風景の動画」のような抽象的な依頼をそのままプロンプト化する | 場所・時間帯・光・被写体の動きを具体化してから書く |
| カメラワークの指定がなく、構図がランダムになる | 文頭に「〇〇ショット」「〇〇アングルの」を必ず入れる |
| セリフや音の指定がなく無音/的外れなBGMになる | セリフは鍵カッコ、SFXは「SFX:」、環境音は「周囲の音:」で明示する |
| 1文に情報を詰め込みすぎて破綻する | タイムスタンプ`[HH:MM-HH:MM]`で複数カットに分割する |
| 除外したい物を「〜なし」と書いて無視される | 代わりに存在するものを肯定文で描写する |

## 出力の型

ユーザーからVeo3.1用プロンプトの作成を頼まれたら、基本的に次の順で応答する。

1. 依頼内容から5要素(映像・被写体・アクション・コンテキスト・スタイル)を整理する
   (情報が不足していれば先に短く確認する)
2. 上記の語彙・書式に沿った日本語(または依頼された言語)のプロンプト本文を1つ提示する
3. 複数ショットにまたがる企画や、長尺の物語調の依頼であれば、タイムスタンプ形式や
   Footage(参照画像)を使う分割案も併せて提示する
4. 必要に応じて、チェックリストで抜けを軽く指摘する
