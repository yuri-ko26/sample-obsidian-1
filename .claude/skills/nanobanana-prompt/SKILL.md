# nanobanana プロンプト作成スキル

nanobanana（Gemini 2.5 Flash Image / Gemini 3 Pro Image）向けに、狙いどおりの画像が出やすい高品質なプロンプトを作るためのガイド。**画像生成AI用**であり、Veoのような動画生成AI用ではない点に注意する（カメラワークの時間経過、クリップ長、セリフ、効果音・環境音といった指示は書かない）。

## 進め方の基本方針

1. ユーザーの依頼を読み、**新規生成**か**既存画像の編集/合成**かを見極める。参照画像が添付されている、または「この画像を」「アップロードした写真を」のような言及があれば編集モード。
2. 本当に曖昧で書き分けようがない場合（例:「かっこいい画像を作って」だけで対象も雰囲気も不明）だけ、要素を1〜2個軽く確認する。ある程度書ける情報があるなら、質問攻めにせず妥当な解釈で組み立てて提示し、フィードバックをもらって直す方が速い。
3. 下記の「要素の並べ方」に沿ってプロンプトを構築する。
4. 完成したプロンプトは、**要素を羅列したタグの寄せ集めではなく、自然な文章（ナラティブ）として**まとめる。nanobananaはシーン全体を理解して推論するモデルなので、「誰が」「どこで」「何をしているか」が繋がった描写の方が精度が上がる。
5. 一度で完璧を狙わない。まずは1案を出し、ユーザーの反応を見て**一度に1つの要素だけ**を変えて調整する（例: 照明だけ変える、構図だけ変える）。

## プロンプトの構成要素と並べる順序

nanobananaは**先に書かれた詳細ほど結果への影響が強い**。重要な要素から順に並べる。

| 順序 | 要素 | 書く内容 |
|---|---|---|
| 1 | 被写体 | 誰/何か。数、年齢、素材、色、形状などを具体的に |
| 2 | 動作・関係性 | 何をしているか、他の人・物とどう関わっているか |
| 3 | 設定（場所・状況） | 場所、時間帯、天気、屋内/屋外、都市/自然など |
| 4 | スタイル・媒体 | 写真/イラスト/3D/水彩/ピクセルアートなど、リアリズムの度合い、アートディレクション |
| 5 | 構図・カメラ | ショットサイズ（クローズアップ/ミディアム/ワイド）、アングル、レンズ（例: 35mm、f/1.8）、被写界深度、被写体の配置 |
| 6 | 照明・色 | ソフト/ハードライト、逆光、ネオン、暖色/寒色、カラーグレーディング |

この6要素を順番に検討し、ユーザーが指定していない要素は文脈から妥当な値を補って自然な一文〜数文にまとめる。要素を分けて見せたい場面（ユーザーが構造を確認したい場合など）だけラベル付きで提示してよい。

## 具体性を最優先する

曖昧な名詞は避け、素材・色・質感まで書く。これはnanobananaの精度に最も効くテクニック。

- ❌「スーツ」→ ✅「ネイビーのツイード素材のスーツジャケット」
- ❌「鎧」→ ✅「銀の葉模様が彫り込まれた装飾的なエルフの板金鎧」
- ❌「女性」→ ✅「ヴィンテージのシャネル風スーツを着たエレガントな年配の女性」
- ❌「マグカップ」→ ✅「ミニマルな白磁のコーヒーマグカップ」

## ポジティブフレーミング

「〜がない」ではなく「〜がある状態」を書く方が伝わりやすい。

- ❌「車がない道」→ ✅「誰もいない静かな通り」
- ❌「散らかっていない部屋」→ ✅「整然と片付いたミニマルな部屋」

除外したいものがどうしても必要な場合は、プロンプトの末尾に制約として明示する（後述の「ネガティブ制約」参照）。

## カメラ・レンズ・構図の語彙

これらの用語を積極的に使うと、写真的なコントロールが効く。

- **ショットサイズ**: クローズアップ / ミディアムショット / ワイドショット / 上半身のショット
- **アングル**: ローアングル、ハイアングル、俯瞰、アイレベル
- **レンズ/被写界深度**: 「35mmレンズ」「浅い被写界深度（f/1.8）で背景をぼかす」「広角レンズで広がりを出す」「マクロレンズで細部を強調」
- **カメラ機材の質感**: GoPro（歪んだ躍動感）、Fujifilm（本物らしい色味）、使い捨てカメラ（粗くノスタルジックなフラッシュ感）

## 照明・カラーの語彙

- **照明設計**: 「3点ソフトボックス照明」（均一）、「明暗のコントラストが強いキアロスクーロ照明」（劇的）、「ゴールデンアワーの逆光で長い影を作る」
- **カラーグレーディング**: 「1980年代のカラーフィルムで撮影したような、わずかに粒子感のある質感」「ティール系のシネマティックなカラーグレーディング」

## 画像編集・合成（参照画像がある場合）

1. **会話的な部分編集（セマンティックマスキング）**: 変更したい箇所だけを具体的な動詞で指示し、それ以外は変更しないことを明言する。
   - 例: 「写真から男性を消してください。背景の建物と空はそのまま残してください」
2. **要素の合成**: ベースになる画像と、追加したいオブジェクトの画像を組み合わせるときは「[参照画像]＋[それぞれの役割]＋[新しいシーン]」の順で説明する。
   - 例: 「添付のナプキンスケッチを形状の参考、添付の布地サンプルを質感の参考として使い、日差しの入るミニマルなリビングルームに置かれた高忠実度の3Dアームチェアのレンダリングに変換してください」
3. **スタイル転写**: 「(元の写真)を(スタイル)風に変換してください」の形で、元の構図・被写体を保ったままスタイルだけ変える。

## 画像内テキストのレンダリング

- レンダリングしたい文字列は**引用符で正確に囲む**（例: "Happy Birthday"）。
- フォントの雰囲気を指定する（例: 「太字の白いサンセリフ体」「流れるようなエレガントなブラシスクリプト体」）。
- 多言語対応が必要なら、まず1言語でプロンプトを作り、テキスト出力の対象言語を別途指定する。
- 複雑なロゴ文字など迷う場合は、先にどんなテキストにするかだけ会話で詰めてから、画像生成本体のプロンプトに組み込むとよい。

## ネガティブ制約（必要な場合のみ、末尾に）

ポジティブな描写を尽くしてもなお除外したいものがある場合は、末尾に短い制約リストとして加える。主役のテクニックにはしない。

例: 「テキストなし、透かしなし、余分な人物なし、変形した手なし、強いモーションブラーなし」

## アスペクト比・解像度

必要に応じて、用途に合ったアスペクト比（例: 1:1, 16:9, 9:16, 4:5 など）や解像度（1K/2K/4K）をプロンプトの意図に添えて提案する。ただしこれは静止画のパラメータであり、動画の尺やフレームレートの話ではないことに注意する。

## 出力の見せ方

- 基本は完成した1つのプロンプトを、自然な文章としてそのまま提示する（コピペしてすぐ使える形）。
- ユーザーが組み立てのロジックを知りたそうな場合のみ、要素ラベル付きの内訳も添える。
- 提示後は「ここを変えたい部分があれば教えてください（1箇所ずつ調整するとブレません）」と一言添え、反復改善へ誘導する。
