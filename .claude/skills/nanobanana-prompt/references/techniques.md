## 5つの活用フレームワーク

### フレームワーク1: 画像生成

**A) テキストのみでの生成**

構成式: `[主題] + [アクション] + [場所/文脈] + [構図] + [スタイル]`

```
[主題] タイトなブラウンドレス、スレックなブーツ、構造化されたハンドバッグを身につけた
印象的なファッションモデル
[アクション] 自信に満ちた姿勢でわずかに体を向けてポーズ
[場所/文脈] シームレスな濃いチェリーレッドのスタジオバックドロップ
[構図] ミディアム・フルショット、中央配置
[スタイル] ファッションマガジン風のエディトリアル、中判アナログフィルムで撮影、
明確な粒子感、高い彩度、シネマティックな照明効果
```

**B) マルチモーダル生成（参照画像あり）**

構成式: `[参照画像] + [関連性指示（何の役割で使うか）] + [新しいシナリオ]`

```
添付のナプキンスケッチを構造の参考として、添付の布地サンプルをテクスチャの参考として
使い、これを高忠実度の3Dアームチェアレンダリングに変換してください。日光が注ぐ、
ミニマリストなリビングルームに配置します。
```

### フレームワーク2: 画像編集

**A) 会話形式の部分編集（セマンティックマスキング/インペインティング）**

テキストで「編集する範囲」を定義し、それ以外は変更しないことを明示する。

```
写真から男性を削除してください。背景はそのまま変更しないでください。
```

**B) 構図・スタイル転写（新しい参照画像あり）**

- ベース画像＋オブジェクト画像をアップロードし、組み合わせ方を具体的に指示する。
- スタイル転写の例: 「現代都市の街並みの写真を、ゴッホの『星月夜』のような筆致とタッチで再構成してください」

### フレームワーク3: Web検索によるリアルタイム情報の反映

構成式: `[検索リクエスト] + [分析タスク] + [ビジュアル翻訳]`

```
Web検索で現在のサンフランシスコの天気と日付を調べてください。
雨が降っている場合は画面全体を灰色がかった雨っぽいトーンにするなど、
このデータを使ってシーンを分析的に修正してください。
これをスマートフォンのUIに埋め込まれたミニチュアシティのコンセプトとして可視化してください。
```

活用場面: 季節・天候に応じたビジュアル、場所固有の最新情報を反映したコンテンツ制作。

### フレームワーク4: テキストレンダリング＆ローカライゼーション

1. **引用符でテキストを明示**: `"Happy Birthday"` のように正確な文字列を引用符で囲む。
2. **フォント指定**: 「太字の白いサンセリフ体」「Century Gothic調の細いミニマルな書体」など。
3. **翻訳・多言語ローカライズ**: 1言語でプロンプトを作った後、出力テキストの対象言語を別途指定する（10言語以上に対応）。
4. **テキストファーストハック**: 込み入ったコピー（キャッチコピーなど）は、先に文言だけを会話で詰めてから、その文言を画像生成プロンプトに組み込む。

```
高級感のある光沢のある商業的な美しさの製品ショット。
スムーズでミニマリストなヌードカラーの保湿クリームのジャー。暖色系のスタジオ背景に配置。

テキスト指定:
- 上段: "GLOW" を流れるようなエレガントなブラシスクリプト体でレンダリング
- 中段: "10% OFF" を太いブロック体のImpact風フォントで
- 下段: "Your First Order" を細いミニマルなCentury Gothic風フォントで

その後、このテキストを韓国語とアラビア語にも翻訳したバージョンを作成してください。
```

### フレームワーク5: クリエイティブディレクターとしてプロンプトする

**照明デザイン**
- 均一な照明: 「3点ソフトボックスセットアップ」
- 劇的な照明: 「明暗のコントラストが強いキアロスクーロ照明」「ゴールデンアワーの逆光で長い影を作る」

**カメラ/レンズ/フォーカス**
- 「ローアングルショット、浅い被写界深度（f/1.8）」
- 「広角レンズで壮大なスケールを表現」
- 「マクロレンズで複雑な細部を強調」
- カメラ機材の質感指定: GoPro=歪んだ躍動的なアクション感、Fujifilm=本物らしいカラーサイエンス、使い捨てカメラ=粗くノスタルジックなフラッシュ感

**カラーグレーディング/フィルムストック**
- ノスタルジック/ざらついた質感: 「1980年代のカラーフィルムで撮影したかのような、わずかに粒子感のある映像」
- モダンで暗めの美学: 「ティール系のミュートトーンによるシネマティックなカラーグレーディング」

**素材・テクスチャの強調**
- 「スーツジャケット」ではなく「ネイビーのツイード素材のスーツジャケット」
- 「鎧」ではなく「銀の葉模様が彫り込まれた装飾的なエルフの板金鎧」

## 用途別テンプレート

### テンプレート1: ファッション/エディトリアル写真

```
[主題] 素材まで指定した具体的な服装を身につけた印象的なモデル
[アクション] 自信に満ちた微妙なポーズ
[文脈] 特定の色のスタジオ背景
[構図] ショットの種類とフレーミング
[スタイル] 雑誌のスタイル、フィルムの種類、粒子感、彩度、照明
```

### テンプレート2: 製品写真

```
[製品の説明。素材・色を具体的に]
[照明設計: 例「特定の配置のスタジオセットアップ」]
[カメラ/レンズ: 具体的なカメラ機種とレンズスペック]
[背景と文脈]
[カラーグレーディングの好み]
```

### テンプレート3: コンセプトビジュアル

```
[核となるコンセプト]
[ビジュアルメタファーや構図]
[カメラの視点: アングルと被写界深度]
[照明のムード]
[カラーパレット/フィルムストック]
[素材・テクスチャの強調]
```

## モデルの技術仕様（参考）

出典: Google Cloud公式ブログ（2025年時点の情報）。バージョンにより変わりうるので目安として扱う。

| 項目 | Nano Banana 2 | Nano Banana Pro |
|---|---|---|
| 入力トークン | 131,072 | 65,536 |
| 出力トークン | 32,768 | 32,768 |
| 解像度 | 0.5K, 1K, 2K, 4K | 1K, 2K, 4K |
| アスペクト比 | 1:1, 3:2, 2:3, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9, 1:4, 4:1, 1:8, 8:1 | 1:1, 3:2, 2:3, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9 |
| 参照画像 | 最大14枚 | 最大14枚 |
| 認証/透かし | C2PA認証、SynthID電子透かし | 同左 |

Nano Banana Proは「Thinkingモデル」（生成前に内部で推論する）であるため、キーワードを羅列する「タグスープ」形式よりも、「誰が・どこで・何をしているか」が繋がった具体的なシーン描写の方が精度が上がる。
